## Робочий контур

Кожен етап — три такти:

1. **Узгодження.** Виношу в головний чат: обсяг етапу, відхилення, які він чіпає, і рішення, яких він потребує. Не починаю, поки не погоджено.
2. **Робота.** TDD, дрібні коміти, окремий PR на етап у `feat/redesign-v3`.
3. **Здача.** Прогін команд приймання (нижче в кожному етапі) + короткий звіт: що зроблено, що виявилось відхиленням по ходу, що лишилось.

**Команди приймання (базові, ганяються на кожному етапі):**

```bash
pnpm -r --parallel typecheck && pnpm -r --parallel test
```

```bash
node scripts/design-audit.mjs --url http://localhost:5173 --email dev@local.test
```

Прогонів моделі (`pnpm eval`) у цьому плані немає **жодного**: редизайн не чіпає промпти. Якщо етап раптом упирається в промпт — це стоп і питання в головний чат, не прогін.

/** Значення токена в блоці, позначеному маркером.

function tokenIn(marker: string, name: string): string | null {
  const start = css.indexOf(marker);
  if (start < 0) return null;
  const block = css.slice(start, css.indexOf('}', start));
