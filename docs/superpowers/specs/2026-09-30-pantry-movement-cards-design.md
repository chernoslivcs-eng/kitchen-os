# Картки руху комори — дизайн (30.09.2026)

Рішення власника з брейншторму 30.09. Замінює логіку «живої» картки додавання
(приглушені gone-рядки, хвіст «ще N … закінчились», текст «Використали: …», олівець
як знак рядка). Спирається на серверний знімок `before` і `source` з PR #235.

## 1. Принцип

Картка в стрічці — запис ОДНОГО руху в коморі. Вона показує, що додали, що списали
і що змінили, і після цього ніколи не переписується. Поточний стан продуктів живе
лише у вкладці «Комора». Залишок у картках не показується ніде.

## 2. Рядки

Знак стоїть біля числа, праворуч; назва продукту — ліворуч, без колонки знаків.

| Подія | Рядок |
|---|---|
| `add` з кількістю | `Молоко` … `+1 л` |
| `add` без кількості | `Сіль` … `+` |
| `deplete`, є `before.value` | `Макарони` … `−500 г` (списане = before) |
| `deplete`, `before.value` null або `before` нема | `Олія` … `−` |
| `correct`, є `before`, ті самі одиниці, value < before | `Сир твердий` … `−100 г` (before − value) |
| `correct`, є `before`, ті самі одиниці, value > before | `Сир твердий` … `+200 г` |
| `correct` без `before` або одиниці не зводяться (старі картки) | `Сир твердий` … `300 г` без знака |
| `open` | `Сметана` … `відкрито` (слово, без знака й числа) |
| `rename` | `Сир → Сир твердий Гауда` (без знака й числа) |

- Одне правило на всі зміни кількості: готування, чат, ручна правка — однаково.
  Олівець як знак рядка зникає.
- Колір: «+» — шавлія (як зараз знак додавання), «−» і числа списання — основний
  колір тексту; слово стану — приглушений. Жодних приглушених рядків.
- Формат числа — той самий, що вже стоїть у рядку кількості (упаковки, одиниці),
  лише з приклеєним знаком.

### 2а. Уточнення після звірки з кодом (30.09)

- **Число додавання.** Кількість `add` — це `value`+`unit` АБО `qty`×`pack`: чотири
  банки по 400 г → `+4 × 400 г`; одна упаковка → `+400 г`. «`add` без кількості → `+`»
  лише коли нема ні того, ні того.
- **`correct` без зміни кількості** (зона, стан, теги, вага упаковки) — рядок зі
  словом без знака, як `open`/`rename`: зона → «у морозилку» / «у холодильник» /
  «на полицю»; стан → «відкрито»; решта → «уточнено». Вага на штучній партії
  (кількість не змінилась) — теж «уточнено», без числа.
- **Готування з пачки.** post-cook на штучній партії дає пару: `correct` (−1 шт) і
  `add` відкритого залишку. Людина при цьому списала частину пачки, а не «мінус
  штука, плюс грами». Сервер позначає таку пару: на `correct` — `used: { value, unit }`
  (скільки пішло в страву), на `add` залишку — `remainder: true`. Веб показує ОДИН
  рядок `Макарони … −250 г` (з `used`), рядок залишку не показує і в N не рахує.
  Якщо `used` є — воно сильніше за різницю `before − value`.

## 3. Слід у стрічці й шапка панелі

Назва за вмістом, слід і шапка однакові:

- усі рядки — плюси: «У комору · N», підрядок «N у комору»;
- усі рядки — мінуси: «Списано · N», підрядок «N з комори»;
- мішане або лише зміни стану (`open`/`rename`): «Комора · N», підрядок «N змін».

Рядки з `remainder: true` у визначенні назви й у N не беруть участі. N — кількість показаних рядків картки. Чекова картка («Чек») лишається як є, рядки — за §2.
Будь-яка картка `intake_diff` має клікабельний слід і відкриває панель; гілка
`isWriteOff → текст` не повертається.

## 4. Продукти без числа

Система ніколи не вгадує кількість (ні типова упаковка, ні уточнювальне питання).
Продукт без числа є або його нема: додали — `+`, закінчився — `−`. Готування його
не списує; у «Списано» він потрапляє лише коли людина скаже, що закінчився.
Поведінка моделі й промпти цим документом не міняються.

## 5. Дані

PR #235 (сервер, без міграції): у ops застосованої картки сервер дописує
`before?: { value: number | null; unit: Unit | null }` для `deplete` і `correct`;
картка списання після готування несе `source?: { kind: 'cook'; at; run_id? }`.
Веб рахує списане як різницю; `source` для вигляду рядка більше не потрібен
(правило одне), лишається для підпису/аналітики.

## 6. Скасування

Скасована картка лишається в стрічці позначеною як скасована (як зараз); її рядки
показуються за §2, рухи не діють.

## 7. Що прибирається

Приглушені gone-рядки і стан `gone` у рендері картки; хвіст «ще N позицій …»;
стрілка «› 800 мл» із залишком; знак-олівець у рядках; текст «Використали: …»;
колонка знаків ліворуч.

## 8. Перевірка

Стенд у памʼяті, одна розмова: (1) «купив продукти» → «У комору · 6», серед них
сіль без числа; (2) готування «Паста з сиром» → «Списано · 3» з `−250 г`, `−100 г`,
`−200 мл`; (3) «доїли йогурт, олія закінчилась» → «Списано · 2» (`−4 шт`, `−`);
(4) «сиру насправді 300 г» → рядок зі знаком за різницею; (5) «відкрив сметану,
купив хліб» → «Комора · 2». Кадри 1440 і 390: стрічка + кожна панель. Картка №1
після кроків 2–3 не змінюється.

## Поза межами

Статистика «зʼїдено/викинуто»; вгадування типової упаковки; зміни промптів;
вкладка «Комора».
