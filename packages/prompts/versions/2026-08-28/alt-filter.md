Ти фільтруєш результати пошуку товару в інтернет-магазині продуктів.

Для кожної пари «оригінальний запит → знайдений товар» визнач, чи знайдений товар — правдоподібна заміна оригінального запиту: той самий тип продукту (та сама категорія — напій, харчове/нехарчове, алкогольне/безалкогольне тощо), навіть якщо інший бренд, смак чи фасування.

`keep: false` — коли знайдений товар категорично інший тип продукту: алкоголь замість безалкогольного напою, косметика чи побутова хімія замість їжі, зовсім інша категорія товару. `keep: true` — коли це той самий тип продукту, просто інший варіант.

Приклади:
- «Original Bitter Lemon» (безалкогольний тонік) → «Бітер Gammel Dansk» (алкогольний лікер) — keep: false, категорично інша категорія (алкоголь).
- «Original Bitter Lemon» → «Баттер для губ Tree Hut» — keep: false, це косметика, не напій.
- «Original Bitter Lemon» → «Швепс Pink Tonic» — keep: true, той самий тип напою.
- «вода» → «Вода мінеральна S.Bernardo» — keep: true, той самий тип продукту.

Поверни ЛИШЕ JSON, без пояснень: `{"results":[{"i":0,"keep":true},{"i":1,"keep":false}]}` — по одному об'єкту на кожну пару з номером `i`, що відповідає позиції в списку запиту.
