# Варіант «компетенція + голос» · порівняльний прогін

Аудит 04.09, раунд 2, крок 2.3 (audit-materials/AUDIT-NEXT-STEPS.md). Два
файли лежать у `versions/2026-08-28/` поряд із наявними і **не входять у
compose** — прод їх не бачить.

- `competence.md` — ремесло: техніка, пріоритети вибору страви, заміни,
  обладнання, «незвичне — не привід відмовляти». Іде в chat і recipe_gen.
- `voice.md` — ToV «Семенівський вайб» у формі правил для моделі: осі
  «ремесло впевнено / сприйняття обережно», формула що→чому→деталь, ліміт
  ~300 (рішення 1.1), кінець репліки лише при card: null, приблизність у
  reply при точній картці, одна усмішка, «де характер зникає», словник
  (вдома/комора), «чого не існує», видимість, відмова, українська, «ти».
  Іде **лише в chat**.
- `attachment_parse` — без обох: там потрібна точність розбору, не голос.

Що з `role.md` НЕ переїхало і має дістати власника до ввімкнення:
- «Картка з поміткою [НЕ ЗАСТОСОВАНО] нічого не змінила» — це правда про
  стан, її місце в `state-facts.md`. Після 3.2 мітка несе причину сама
  («у профілі цього ще НЕМАЄ»), тож частково покрито; але рядок у
  state-facts варто додати тим самим комітом, що вмикає варіант.
- Абзац про алергію на прямий запит — лишається в `kitchen-policy.md`
  (chat) і `recipe-generator.md` (recipe_gen); `competence` на нього
  посилається, не повторює. Це закриває 2 з 8 файлів у маркері `allergen`.

## Як прогнати порівняння (тимчасово, не комітити manifest)

У `manifest.json` замінити compose:

```json
"chat":             ["competence", "onboarding-stage1?", "onboarding-stage2?", "card-contract", "state-facts", "voice", "card-schemas", "card-routing", "kitchen-policy", "proposal-flow"],
"recipe_gen":       ["competence", "recipe-generator"],
"attachment_parse": ["attachment-parser"]
```

Порядок збережено: компетенція першою (як був role), голос там, де був
tone-language — після state-facts, перед схемами. Далі:

```
pnpm --filter @kitchen/eval start 2>&1 | tail -80
git checkout -- packages/prompts/versions/2026-08-28/manifest.json
```

Порівнювати з `snapshots/latest.json`: інваріанти ті самі. Окремо — 20
реплік proposal/intake очима на ToV-рубрику (одна усмішка, спершу
відповідь, без жаргону). Хеш префікса зміниться — це очікувано, у
CHANGELOG при ввімкненні.
