# Prompt versions

Кожна відповідь моделі логується з версією промпту. Без цього після зміни формулювання неможливо зрозуміти, чому якість поїхала.

Правила:
- зміна ROLE або схеми картки — мінорна версія (`2026-09` замість `2026-08`)
- зміна одного правила в блоці — патч (`2026-08-28a`)
- перед комітом — `pnpm eval`. Дифи інваріантів між снапшотами йдуть у комітмесідж
