# shelf-photo (плейсхолдер)

Реальний файл: `shelf-photo.jpg`, ~800 KB, знімок полиці холодильника з неоднозначними продуктами:

- пучок зелені, який виглядає як петрушка або кінза (плоскі листя)
- три червоних плоди — не ясно, кумато чи звичайні бички
- пляшка молочного продукту без наліпки видимого боку
- відкрита пачка сиру, назва частково закрита іншим продуктом
- прозорий пакет із чимось білим (сир? тофу?)

Інваріанти для розбору (див. `packages/eval/invariants.ts` → `shelfSpec`):
- `ev: visual_guess` на кожній позиції
- `conf` нижче 0.7 для впевненого, нижче 0.6 для сумнівних
- жодного вигаданого сорту («томат», а не «кумато»)
- `note` — одне речення, наступний крок або сумнів

## Як додати справжнє фото

Поклади `shelf-photo.jpg` (jpeg, ≤1400 px по більшій стороні, ≤2 MB) поруч із цим файлом. Раннер побачить `.jpg` і візьме його; поки нема — фікстура позначена `skip:"no image"` і не заваджає прогону решти.
