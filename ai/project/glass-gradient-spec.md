# Градієнт і скло · специфікація v3.1

Стан на 11.09. Передавати разом: цю специфікацію + `Kitchen OS - Prototype.dc.html` як робочий еталон (звідти копіюється оболонка й перевіряються обидві теми). Реалізовано в `Prototype`, `Screens`, `Responsive`, `Components` (там же токени `--glass-*`, `--chat-grad` і класи `.glass-rail` / `.glass-panel`). Лишилось перенести в `Cook and Share`, `Errors`, `Auth`, `Onboarding`.

Правило одним рядком: **скло — спільний матеріал усього продукту, градієнт — ознака тільки розмови.**

---

## 1. Токени

Додати в обидва блоки токенів (`.v3` і `.v3[data-theme="dark"]`) кожного файлу. Перевірка після правки: `--glass-edge:` має зустрічатись ДВІЧІ, не раз.

```
/* світла */
--glass-edge:rgba(255,255,255,.7);
--glass-top:rgba(255,255,255,.9);
--glass-side:rgba(255,255,255,.5);

/* темна */
--glass-edge:rgba(255,255,255,.10);
--glass-top:rgba(255,255,255,.16);
--glass-side:rgba(255,255,255,.07);
```

Два значення віддаються з логіки (бо залежать від теми, а не від елемента):

```js
glassBg: theme === 'dark'
  ? 'color-mix(in srgb, var(--card) 78%, transparent)'
  : 'color-mix(in srgb, var(--card) 72%, transparent)',
glassSh: theme === 'dark'
  ? '0 12px 40px rgba(0,0,0,.5), 0 0 0 1px rgba(255,255,255,.06)'
  : '0 12px 40px rgba(26,28,30,.16), 0 0 0 1px rgba(255,255,255,.6)',
```

## 2. Градієнт

Живе на **рамці екрана** (спільний предок рейки, контенту й артефакта), а не на колонці контенту. Якщо повісити на колонку — поява артефакта зсуває його, і шов видно.

```js
frameBg: screen === 'chat'
  ? (theme === 'dark'
    ? 'linear-gradient(to bottom, color-mix(in srgb, var(--sage-bg) 65%, var(--bg)) 0, var(--bg) 260px)'
    : 'linear-gradient(to bottom, color-mix(in srgb, var(--amber-bg) 32%, var(--bg)) 0, var(--bg) 240px)')
  : 'var(--bg)',
```

- Світла — бурштин 32 %, 240 px. Слабше за лендінг: продукт дивлять годинами.
- Темна — **шавлія** 65 %, 260 px. Бурштин на чорнилі читається як бруд, до того ж бурштин зайнятий родом «горить/почекати».
- Решта екранів — рівний `var(--bg)`, без винятків.

## 3. Скло

Матеріал спільний для ВСІХ екранів, незалежно від градієнта. Скло без градієнта виглядає просто як мʼяка панель — це нормально й очікувано.

### Що зі скла

1. **Ліва рейка 60** і **розгорнутий сайдбар 240**
2. **Артефакти правої панелі**: рецепт, чек, кошик, картка позиції, подія календаря
3. **Нижній бар на 390**
4. **Шторки на 390** (ті самі артефакти в мобільному режимі)

### Що НЕ зі скла

Картки контенту (`--card` без прозорості): зони комори, рядки списку, картки рецептів, бабли повідомлень, тости, модалки, картка кроку в Cook Mode. Інакше вся сторінка починає «плавати».

### Оболонка артефакта — ОДИН шаблон

Усі пʼять артефактів (рецепт, чек, кошик, картка позиції, подія календаря) використовують ту саму оболонку; відрізняється лише вміст усередині `.art-inner`. Тому «скло на артефакти» — одна правка на файл, не пʼять. Те саме на 390: шторка — та сама оболонка з іншою геометрією (`.sheet-on`).

### Рецепт оболонки (двошарова конструкція)

Зовнішня оболонка тримає геометрію й тінь, внутрішній шар — розмиття й контур. Один елемент не тягне і те, і те: `overflow:hidden` для контенту сперечається з ручкою ресайзу й тінню.

```html
<aside class="artifact glass" style="width:{{ asideW }}px; border-radius:16px;
       box-shadow:{{ glassSh }}; overflow:visible; position:relative;">
  <div onMouseDown="{{ asideDragStart }}"><!-- ручка ресайзу, 12px, зліва --></div>
  <div class="art-inner" style="position:absolute; inset:0; border-radius:16px; overflow:hidden;
       display:flex; flex-direction:column; background:{{ glassBg }};
       backdrop-filter:blur(18px) saturate(1.25); -webkit-backdrop-filter:blur(18px) saturate(1.25);">
    <!-- вміст -->
  </div>
</aside>
```

CSS (у `<helmet>`, бо псевдоелемент інлайном не задати):

```css
.glass { isolation:isolate; }
.glass > .art-inner::after {
  content:''; position:absolute; inset:0; border-radius:inherit; pointer-events:none;
  border:1px solid var(--glass-edge);
  box-shadow:inset 0 1px 0 var(--glass-top), inset 1px 0 0 var(--glass-side);
}
```

Рейка й сайдбар — одношарові, без псевдоелемента:

```
background:{{ glassBg }};
backdrop-filter:blur(18px) saturate(1.25); -webkit-backdrop-filter:blur(18px) saturate(1.25);
border-right:1px solid var(--glass-edge);
box-shadow:inset -1px 0 0 var(--glass-side);
```

Нижній бар на 390 — те саме, але `border-top` і `inset 0 1px 0`.

## 6. Пастки, на яких я вже спіткнувся

1. **Селектори по інлайн-стилю не працюють.** React пише `style="position: relative"` з пробілом, тож `[style*="position:relative"]` не матчить. Мобільні правила чіпляти класами (`.artifact`, `.art-inner`), не підстрічкою стилю.
2. **Токени треба в обидва блоки.** Якщо `--glass-*` є тільки в темному, у світлій темі `border:1px solid var(--glass-edge)` стає невалідним — і рейка втрачає навіть ту межу, що була. Після правки грепнути: два входження.
3. **Градієнт на колонці ≠ градієнт на рамці.** На колонці він зсувається, коли відкривається артефакт.
4. **`justify-content:flex-end` на стрічці ламає скрол** — верх виїжджає за межі й недосяжний. Притискати донизу через `margin-top:auto` в першого елемента.
5. **`backdrop-filter` потребує непрозорого предка.** Якщо під скляним шаром теж скло, розмиття множиться й поверхня сіріє. Тому `.glass { isolation:isolate; }` і жодного скла всередині скла.
6. **Кількість скла.** Максимум дві скляні поверхні в кадрі (рейка + артефакт). Третя — і глибина зникає.
7. **Не дублювати оболонку.** Якщо в файлі кілька артефактів — правити один шаблон і перевикористати; пʼять копій розʼїжджаються з першою ж правкою радіуса або тіні.
