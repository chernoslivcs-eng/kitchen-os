# Пороги design-audit.mjs · напрям 3

Запускати з першого екрана нового фронта: `node scripts/design-audit.mjs --url http://localhost:5173 --email dev@local.test`

| Метрика | Поріг | Чому |
|---|---|---|
| стилів (кегль × вага × гарнітура) на екран | ≤ 8 | 10 ролей у tokens-v3, на одному екрані живуть не всі |
| найчастіший кегль («часто») | 14–16 | контент, не мікро-мітка; зараз 10–11 на трьох екранах |
| макс. кегль | 32 (Cook: 112) | h1; display лише в Cook Mode |
| display ÷ body | 2.0 ± 0.1 | 32 / 16 |
| елементів display-поверху | ≤ 2 | заголовок + одне число |
| гарнітур | 1 | Onest |
| написань трекінгу | ≤ 4 | -0.03 / -0.02 / -0.01 / 0.01em |
| ваг | 3 | 400 / 500 / 600 (700 тільки h1/display) |
| роздільники з контрастом < 1.5:1 | 0 | line на card = 1.6:1 у світлій, перевірити в темній |
| текст із контрастом < 4.5:1 | 0 | dim тільки ≥ 13px і ≥ 4.5 на card |
| текстових гліфів (◉ ▤ ❋ ☰ ◷ ◈ ✳ ● ✕ ↩ ↗) | 0 | усе — Lucide |
| навігація дрібніша за контент | ні | рейка 14/500, контент 15–16 |
| виділених рядків (600 + колір) на екран | ≤ 3 + 1 картка | правило емфази |
| інлайнових кеглів у компонентах | 0 | лише ролі |
| чисел на екрані до приходу даних | 0 | скелетон без лічильників |

Пороги обох тем однакові. Ієрархія небезпечних дій перевіряється окремо: «Видалити акаунт» не має бути контрастнішим за «Вийти» в жодній темі.
