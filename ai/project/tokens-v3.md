## Простір

Крок 4. Рядок списку 48 (десктоп) / 56 (тач). Контроли 36 · 44. Відступи картки 16 · 20 · 24. Проміжок між картками 12 · 16. Колонка розмови 720.

## Поверхні

Три площини: `bg` (екран) → `card` (картка/панель, тінь sh-a+sh-b) → `bg` як тінт усередині картки (блок таймера, активний рядок). Рамка `line2` — тільки контроли й контурні кнопки. Тіні: sh-a 0 1px 2px · sh-b 0 8px 24px · панель 0 16px 48px.

## Радіуси (усі — continuous / squircle)

8 контрол · 12 рядок-картка, кнопка · 16 картка · 20 панель, шторка · 24 Cook Mode картки · pill.

## Знаки

Lucide, сітка 24, штрих 1.75, round cap/join. Розміри 16 (в тексті) · 20 (інтерфейс) · 24 (Cook). Жива зона 44. Колір `muted` у спокої → `ink` на ховері/активний. Текстові гліфи заборонені. Три сім'ї: система (з моушном) · продукти · готування (статичні).

## Слоти рядка комори (три осі)

```
[шкала свіжості 56×4] [назва row · паспортна caption dim] [безпека] [походження] [час caption] [кількість caption]
```
- час: `свіже до 14 вер` · `≈ ще 5 дн` · `не псується` · `розрахунок скінчився` (danger) — слово + шкала
- безпека: `не їм` (plum контур) · `не можна` (plum заливка + ban)
- походження: іконка 12 — receipt · pencil · message-circle · list-checks
- пороги свіжості: 3 / 5 / 1 — одне місце

## Скло і градієнт (v3.1)

Правило: **скло — матеріал усього продукту, градієнт — ознака тільки розмови.**

Токени в обидва блоки (`.v3` і `.v3[data-theme="dark"]`):

| Токен | Світла | Темна |
|---|---|---|
| `--glass-bg` | `color-mix(in srgb, var(--card) 72%, transparent)` | `… 78% …` |
| `--glass-edge` | `rgba(255,255,255,.7)` | `rgba(255,255,255,.10)` |
| `--glass-top` | `rgba(255,255,255,.9)` | `rgba(255,255,255,.16)` |

| `--chat-grad` | бурштин 32 %, 240 px | шавлія 65 %, 260 px |

Два класи (у `<helmet><style>`, бо псевдоелемент інлайном не задати):

```css

.glass-panel { background:var(--glass-bg) !important; backdrop-filter:blur(18px) saturate(1.25); -webkit-backdrop-filter:blur(18px) saturate(1.25); position:relative; isolation:isolate; }
.glass-panel::after { content:''; position:absolute; inset:0; border-radius:inherit; pointer-events:none; border:1px solid var(--glass-edge); box-shadow:inset 0 1px 0 var(--glass-top), inset 1px 0 0 var(--glass-side); }
```

Зі скла: рейка 60 / сайдбар 240–256, артефакти правої панелі (один шаблон на всі), шторки й нижній бар на 390. Щільні (`--card`): картки контенту, бабли, тости, модалки, картка кроку Cook Mode. Максимум дві скляні поверхні в кадрі.

`--chat-grad` вішається на **рамку екрана** (спільний предок рейки, контенту й артефакта) — на колонці він зсувається з появою панелі. Живі приклади: Components М1 / М2.

## Правка канону 11.09 (рішення власника)

Розміри — як на кадрах Screens, не як у тексті. Три числа переміряно з рендеру
кадрів (`scripts/side-by-side.mjs` рендерить `.dc.html` у Chromium): h1 32 → 28
на 1440 / 26 на 390; display 40 → 36; сайдбар 240 → 256. Підстава — попереднє
`Redesign.dc.html` → Screens зменшили h1 (32 → 26–28), а таблиця лишилась
старою (`CORRESPONDENCE-V3.md`, «Трішки зменшити»). Кожне число — з кадром,
звідки взяте, у самій таблиці. Решта ролей не мінялась.
